== AcquisitionState (class)
Metadata describing microscope state at the time of acquisition
  .acqHW: 
  .acquisitionType: 
  .annotations: 
  .applicationID: name and version number of the software package used to create the image
  .appliedBrightness: as currently applied by the Phenom
  .appliedContrast: as currently applied by the Phenom
  .appliedGamma: as currently applied by the Phenom
  .beamShift: optional [m]
  .bsdGain: [dB]
  .bsdMixFactor: mix factor of the BSD signal in the acquisition
  .bsdOffset: [V]
  .colorLabels: 
  .cropHint: rectangle with full integration signal (drift correction)
  .currentUser: user currently logged in on Phenom
  .dataBarFields: selected data bar fields, see ppi.DatabarField constants
  .dataBarHeight: data bar height in pixels
  .dataBarLabel: data bar label
  .detector: detector mode used for the acquisition
  .detectorMixFactors: detector mix factors used for the acquisition
  .displayBlackLevel: black level used for display, relative to full scale 0..1
  .displayWhiteLevel: white level used for display, relative to full scale 0..1
  .displayWidth: display width [meter]
  .dwellTime: pixel dwell time [second] (only valid for SEM images)
  .emissionCurrent: emission current [Ampere]
  .emissionCurrentPresetName: emission current preset name
  .filamentPower: electron source filament power [Watt]
  .highVoltage: acceleration voltage [Volt]
  .instrumentEdition: 
  .instrumentID: 
  .instrumentType: 
  .integrations: 
  .interlace: scan interlace
  .multiStage: Multi-axis stage position
  .pixelSize: [meter]
  .position: stage position in [meter]
  .rotation: scan rotation in [radian]
  .sampleHeight: [m]
  .sampleHolderID: optional
  .sampleHolderType: optional
  .samplePressureEstimate: [Pa]
  .sampleRadius: [m]
  .scanCenter: Center of the scan in the available range
  .scanHW: 
  .scanScale: Scale of the scan in the available range
  .sedGain: [dB]
  .sedMixFactor: Factor of the SED signal in the acquisition
  .sedOffset: [V]
  .sedScintillatorVoltage: [V]
  .segments: detector configuration used for the acquisition
  .softwareVersion: 
  .sourceId: ID of the electron source module
  .sourceTilt: 
  .sourceTime: total time [hour] the electron source has been "on"
  .spotPresetName: optional
  .spotSize: optional
  .stemMixFactor: 
  .stemSegmentSelection: 
  .stigmator: 
  .time: [seconds since epoch]
  .workingDistance: distance from sample to lens [meter]

== NavigationAlgorithm (type)
Algorithm for stage moves during navigation.
The Phenom stage is accurate to about 35 um in point-to-point movements, but can achieve considerably better accuracy if
so-called "backlash correction" is applied, in which the stage is programmed to approach the destination position always
from the same direction. This mode is not available from the GUI, which always uses direct single stage movements or jogging.
Backlash correction only increases point-to-point accuracy when the previous stage movements also used the correction.
Immediately after a single direct movement or a stage jogging movement, the accuracy of the next backlash-corrected stage movement
will not be better.
Auto          -- Let the Phenom decide which algorithm to use
BacklashOnly  -- Always perform backlash correction
Raw           -- Use single stage moves only

  .SemAutoSourceTilt: SemAutoSourceTilt( (Phenom)arg1) -> None :
    Perform an automatic source tilt alignment.
    This may take up to several minutes if the current settings
    are very far from the optimal values, since the Phenom will then perform a full scan of all possible source
    tilt settings to determine the optimal values.  Note that on the Phenom itself, this algorithm is only available
    in "expert" mode, on the source tilt alignment page.  The values found with the algorithm are persistent
    (i.e., they will stay in effect even if the Phenom is brought to standby, hibernate, or even switched off and
    back on again).
    Forcing an auto source tilt alignment is not recommended,
    since the optimal position is only valid when the electron source has been "on" for a longer period of time
    (at minimum half an hour); changing the alignment may result in deterioarated image quality once the source
    reaches its optimum working conditions.
